OPT.AI Rules API – Demo & Testoberfläche

Fachliche Demonstration und technisches Testwerkzeug für die OPT.AI Rules API: Herkunfts- und Zielland sowie Warennummer eingeben, die API entscheidet selbst, welches Abkommen zutrifft, und liefert die passenden Ursprungsregeln.

Dies ist eine Demo-/Testoberfläche, keine Präferenzkalkulation. Bei mehreren möglichen Ursprungsregeln (RuleSets) trifft diese Seite keine fachliche Auswahl – sie zeigt transparent, was die API liefert.

Regel abfragen

Abgangsland, Zielland und Warennummer angeben. Das Abkommen wird von der API automatisch ermittelt und erst im Ergebnis angezeigt.
